# 實機驗收清單（發布前）

自動測試已經驗證了 RIME 引擎裡的所有輸入行為。這份清單檢查的是**只能在 iPhone 上確認的部分**：倉輸入法能不能讀懂鍵盤設定、按鍵手感，以及實際安裝流程。

每一項都打勾後才發布。發現問題時記下截圖和步驟。

## 0. 準備

- [ ] 記錄測試環境：iPhone 型號＿＿＿、iOS 版本＿＿＿、倉輸入法版本＿＿＿（App 內「關於」）
- [ ] 在電腦執行 `python build.py --package`，把 `dist/` 裡的兩個 hamster zip 傳到手機（AirDrop 或 iCloud 雲碟都可以）

## 1. 決定鍵盤語法（最重要，先做）

倉輸入法的自訂鍵盤格式改過，目前版本用哪一種要實際試過才知道（見 `design.md`「兩種鍵盤語法」）。

**快速查法**：倉輸入法 App 裡有檔案瀏覽功能，打開 `SharedSupport/hamster.yaml`，搜尋 `keyboards`，看裡面倉頡鍵盤的按鍵怎麼寫：

- 寫成 `action: { character: { char: q } }` → 新語法（`wiki`）
- 寫成 `action: character(q)` → 舊語法（`legacy`）

**實測**：

- [ ] 匯入 `rime-sanjiao-<版本>-hamster.zip`（wiki 語法），照 `install-iphone.md` 第 5、6 步操作。鍵盤是否出現三角數字鍵盤？＿＿＿
- [ ] 如果沒有出現，或倉輸入法顯示錯誤：改匯入 `-hamster-legacy.zip` 再試一次。結果＿＿＿

**確認後要修改的地方**：如果是 legacy 語法才正確，就把 `build.py` 的 hamster zip 改用 legacy 那份，並把結果記到 `design.md`。

## 2. 安裝流程（照 install-iphone.md 從頭做一次）

- [ ] 每一步的畫面文字都和教學一致（不一致的地方記下來，修正教學）
- [ ] 匯入後「输入方案设置」裡有「三角編號」
- [ ] 鍵盤自動切換成三角鍵盤（或需要手動到「键盘布局」選）＿＿＿

## 3. 鍵盤外觀

- [ ] 4 列 × 5 個鍵，排列和教學圖一樣
- [ ] 數字鍵、標點鍵上的字清楚，滑動提示（；：！「」）有顯示
- [ ] ⌫、換行、🌐 有顯示圖示
- [ ] 空格鍵一開始短暫顯示「三角編號」，之後顯示「空格」
- [ ] 深色模式下也看得清楚
- [ ] 橫向時版面正常

## 4. 輸入（在「備忘錄」測）

- [ ] `101010` → 候選出現「三」，點它輸入「三」
- [ ] `101010` 再按空格 → 輸入「三」
- [ ] `101010305354` 再按空格 → 輸入「三我」（連打）
- [ ] `101` → 第一個候選是「二」
- [ ] `331120` → 候選依序：汗、汙、涆、滒、泟、𣵼（最後一個可能顯示成方框，正常）
- [ ] 選第 4 個「滒」後再打 `331120`，順序不變
- [ ] `999999` 再按空格 → 什麼都沒輸入，編碼還在；按 ⌫ 刪成 `99999`
- [ ] 在 ⌫ 上往上滑 → 編碼整串清除
- [ ] `2026` 再按換行 → 輸入「2026」
- [ ] 什麼都沒打時按空格 → 輸入一個空白
- [ ] 什麼都沒打時按換行 → 換行

## 5. 標點

- [ ] 「，」「。」「？」「、」各按一次 → 輸入全形標點
- [ ] 上滑：「，」→「；」、「。」→「：」、「？」→「！」、「、」→「「」
- [ ] 下滑：「、」→「」」
- [ ] `101010` 後直接按「，」→ 輸入「三，」

## 6. 切換

- [ ] 「符號」→ 符號鍵盤 → 返回鍵回到三角鍵盤
- [ ] 「ABC」→ 英文鍵盤，可以打英文 → 返回鍵回到三角鍵盤
- [ ] 🌐 → 切換到下一個輸入法；長按 🌐 → 出現輸入法清單

## 7. 實際使用

- [ ] 在 LINE、Safari 網址列、Threads 各打一句話
- [ ] 密碼欄位會自動換成系統鍵盤（正常，不是錯誤）
