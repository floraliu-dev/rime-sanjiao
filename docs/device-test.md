# 實機驗收清單（發布前）

自動測試已經驗證了 RIME 引擎裡的所有輸入行為。這份清單檢查的是**只能在 iPhone 上確認的部分**：倉輸入法能不能讀懂鍵盤設定、按鍵手感，以及實際安裝流程。

每一項都打勾後才發布。發現問題時記下截圖和步驟。

## 0. 準備

- [ ] 記錄測試環境：iPhone 型號＿＿＿、iOS 版本＿＿＿、倉輸入法版本＿＿＿（App 內「關於」）
- [ ] 在電腦執行 `python build.py --package`，把 `dist/` 裡的 `-hamster.zip` 傳到手機（AirDrop 或 iCloud 雲碟都可以）

## 1. 鍵盤能不能顯示（先做）

- [ ] 匯入 `rime-sanjiao-<版本>-hamster.zip`，照 `install-iphone.md` 第 5、6 步操作。鍵盤是否出現三角數字鍵盤？＿＿＿

如果沒有出現，可能是倉輸入法又改了自訂鍵盤的格式：打開 App 裡的 `SharedSupport/hamster.yaml`，對照內建鍵盤按鍵的寫法和 `design.md`「鍵盤語法」。

## 2. 安裝流程（照 install-iphone.md 從頭做一次）

- [ ] 每一步的畫面文字都和教學一致（不一致的地方記下來，修正教學）
- [ ] 匯入後「輸入方案設定」裡有「三角編號」，並在「已選輸入方案」排第一個
- [ ] 叫出鍵盤後**不點 ®**，直接打 `101010` 就有候選（方案預設就是三角編號）
- [ ] 鍵盤自動切換成三角鍵盤（或需要手動到「鍵盤佈局」選）＿＿＿

## 3. 鍵盤外觀

- [ ] 4 列 × 5 個鍵，排列和教學圖一樣
- [ ] 數字鍵、標點鍵上的字清楚，滑動提示（；：！「」）有顯示
- [ ] ⌫、換行、🌐 有顯示圖示
- [ ] 用 ® 切換到三角編號時，空格鍵短暫顯示「三角編號」，之後顯示「空格」（重新叫出鍵盤時不會顯示，正常）
- [ ] 深色模式下也看得清楚
- [ ] 橫向時版面正常

## 4. 輸入（在「備忘錄」測）

- [ ] `101010` → 打完第 6 碼直接輸入「三」，不必選
- [ ] `101010305354` → 輸入「三我」（連打）
- [ ] `140400` → 候選「玟、玫」，不會自動送出；點「玫」輸入「玫」
- [ ] `26` 再按換行 → 輸入「月」
- [ ] `10101` 再按空格 → 輸入「三」
- [ ] `101` → 第一個候選是「二」
- [ ] `331120` → 候選依序：汗、汙、涆、滒、泟、𣵼（最後一個可能顯示成方框，正常）
- [ ] 選第 4 個「滒」後再打 `331120`，順序不變
- [ ] `442956` → 打完第 6 碼立刻清空（`44295` 時還有候選「蓁」）
- [ ] `442958` → 候選只有「蓁」
- [ ] 在 ⌫ 上往上滑 → 編碼整串清除
- [ ] 什麼都沒打時按空格 → 輸入一個空白
- [ ] 什麼都沒打時按換行 → 換行

## 5. 標點

- [ ] 「，」「。」「？」「、」各按一次 → 輸入全形標點
- [ ] 快速往上撥：「，」→「；」、「。」→「：」、「？」→「！」、「、」→「「」
- [ ] 下滑：「、」→「」」
- [ ] `101010` 後直接按「，」→ 輸入「三，」

## 6. 切換

- [ ] 「符號」→ 符號鍵盤 → 返回鍵回到三角鍵盤
- [ ] 「ABC」→ 英文鍵盤，可以打英文 → 返回鍵回到三角鍵盤
- [ ] 🌐 → 切換到下一個輸入法；長按 🌐 → 出現輸入法清單

## 7. 實際使用

- [ ] 在 LINE、Safari 網址列、Threads 各打一句話
- [ ] 密碼欄位會自動換成系統鍵盤（正常，不是錯誤；螢幕錄影或 QuickTime 畫面裡看不到密碼鍵盤，要看手機本身）
