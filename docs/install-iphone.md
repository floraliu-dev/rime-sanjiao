# 在 iPhone 安裝三角編號輸入法

大約需要 5 分鐘，完全免費。

這個輸入法要裝在免費的「倉輸入法」App 裡面使用。倉輸入法是一個可以載入各種輸入法方案的 App，三角編號就是其中一種方案。

> 下面寫的是倉輸入法畫面上實際看到的字（iPhone 語言設為繁體中文時）。不同版本的文字可能略有差異。

## 1. 安裝倉輸入法

在 App Store 搜尋「倉輸入法」（畫面上顯示為「仓输入法」），下載安裝。

## 2. 在 iPhone 設定裡加入鍵盤

1. 打開 iPhone 的「設定」→「一般」→「鍵盤」→「鍵盤」→「新增鍵盤⋯」
2. 在「協力廠商鍵盤」找到「仓输入法」，點一下加入。
3. 回到鍵盤清單，點「仓输入法」，打開「允許完整取用」。

**為什麼要開完整取用？** 倉輸入法的說明要求開啟這個權限，讓鍵盤能讀到 App 裡設定好的輸入法資料。三角編號方案本身只是設定檔和碼表，不會連網，也不會收集任何資料。倉輸入法本身如何處理資料，請參考它在 App Store 上的隱私權說明。

## 3. 先打開倉輸入法一次

打開倉輸入法 App。第一次打開時它會自動做初始設定（畫面顯示「部署」），等它完成。

## 4. 下載並匯入三角編號

1. 用 iPhone 的 Safari 打開 [最新版下載頁](https://github.com/floraliu-dev/rime-sanjiao/releases/latest)，點 `rime-sanjiao-<版本>-hamster.zip` 下載。
2. 打開「檔案」App →「下載項目」，找到剛下載的 zip 檔。
3. **長按** zip 檔 →「分享」→ 選「倉輸入法」。如果清單裡沒有，往右滑到最後點「更多」找。
   不要直接點 zip 檔：點一下會被「檔案」App 解壓縮成資料夾，不會匯入。
4. 倉輸入法會自動打開並匯入，等它完成。

**注意**：如果你之前已經自己改過倉輸入法的設定檔（`default.custom.yaml` 或 `hamster.custom.yaml`），匯入會取代它們。這種情況請改看下方「已經有自訂設定的人」。

## 5. 選擇三角編號

1. 在倉輸入法 App 裡點「輸入方案設定」。
2. 確認「三角編號」有勾選，而且在下方「已選輸入方案」排**第一個**（匯入時會自動排好）。倉輸入法每次叫出鍵盤都會用排第一的方案。
3. 如果清單裡沒有「三角編號」：回到首頁點「RIME」→「重新部署」，再回來找一次。

## 6. 開始打字

1. 打開「備忘錄」，點一下輸入區叫出鍵盤。
2. 按住左下角的 🌐，選「仓输入法」。
3. 應該會看到三角編號的數字鍵盤。如果看到的是英文字母鍵盤，請到倉輸入法 App 的「鍵盤設定」→「鍵盤佈局」，選「三角編號」。

試試看：輸入 `101010`，候選列會出現「三」，點它就會輸入。

## 鍵盤用法

```
符號   7   8   9   ？
、     4   5   6   空格
🌐     1   2   3   ⌫
ABC    ，  0   。  換行
```

| 想做什麼 | 怎麼做 |
|---|---|
| 選字 | 打滿 6 碼而且只有一個字時會直接輸入；有好幾個字時，點候選列上的字，或按「換行」選第一個 |
| 連續打字 | 打滿 6 碼後直接打下一個字的編碼，會自動輸入第一個候選 |
| 少打幾碼 | 編碼結尾的 0 可以省略，例如「月」260000 只要打 `26` 再按「換行」 |
| 打錯編碼 | 打到查不到字的編碼會自動清空，直接重打；也可以按 ⌫ 刪一碼，或在 ⌫ 上**往上滑**清除整串 |
| 輸入數字本身 | 按「符號」或「ABC」切到其他鍵盤 |
| 其他標點 | 在鍵上**快速往上撥**（滑太慢不會輸入）：「，」往上滑是「；」、「。」往上滑是「：」、「？」往上滑是「！」、「、」往上滑是「「」、往下滑是「」」 |
| 更多符號 | 按「符號」 |
| 英文 | 按「ABC」 |
| 換其他輸入法 | 按 🌐 |

候選字的順序是固定的：常用字在前、罕用字在後，同一個編碼每次都是同樣的順序，方便記住位置。

## 已經有自訂設定的人

下載 `rime-sanjiao-<版本>-schema-only.zip`，裡面只有 `sanjiao.schema.yaml` 和 `sanjiao.dict.yaml`。匯入後，在你自己的 `default.custom.yaml` 的 `patch` 裡加上：

```yaml
  schema_list/@before 0:
    schema: sanjiao
```

這樣會把三角編號排在方案清單最前面。倉輸入法每次都用排第一的方案，排在後面就得每次手動切換。

鍵盤設定可以從 hamster 安裝包裡的 `hamster.custom.yaml` 複製 `keyboards` 那一段，合併進你自己的檔案。

## 常見問題

**找不到「三角編號」方案**：倉輸入法 →「RIME」→「重新部署」。

**鍵盤是英文字母，不是數字**：「鍵盤設定」→「鍵盤佈局」→ 選「三角編號」。

**打數字直接出現數字，沒有候選字**：目前用的是別的方案。到「輸入方案設定」，把「已選輸入方案」裡的「三角編號」拖到第一個；或在鍵盤左上角點 ® 切換成三角編號（只對這次有效）。

**某些字顯示成方框**：那是 Unicode 擴充區的罕用字，iPhone 字型沒有收錄。它們一律排在候選列最後面，不影響常用字。

**有些 App 裡叫不出來**：密碼欄位，以及部分銀行或公司的 App，會強制使用 iPhone 內建鍵盤，這是 iOS 的規定。

**想回報問題**：到 [GitHub Issues](https://github.com/floraliu-dev/rime-sanjiao/issues) 留言，附上你的 iPhone 型號、iOS 版本和倉輸入法版本。
